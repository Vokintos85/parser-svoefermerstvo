# SvoeFermerstvo Email Scraper

Инструмент для сбора email-адресов из каталога компаний на сайте
[svoefermerstvo.ru](https://svoefermerstvo.ru/).

## Возможности

- Обход всех страниц каталога и карточек компаний (20 карточек на странице).
- Переход во вкладку «Адреса и доставка» и извлечение всех email-адресов.
- Ожидание появления элементов страницы и случайные задержки между запросами.
- Обработка всплывающих окон (куки, выбор региона).
- Сохранение прогресса в JSON-файл и продолжение с места остановки.
- Экспорт собранных данных в Excel (`.xlsx`).
- Ведение логов о ходе работы и ошибках.

## Установка

1. Установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. Убедитесь, что Chrome/Chromium и соответствующий ChromeDriver доступны в системе.

## Использование

```bash
python run_parser.py [опции]
```

Основные опции:

- `--output` — путь к Excel-файлу с результатами (по умолчанию `output/emails.xlsx`).
- `--progress` — путь к JSON-файлу прогресса (по умолчанию `output/progress.json`).
- `--log-file` — путь к лог-файлу (по умолчанию `output/parser.log`).
- `--headless/--no-headless` — включить или отключить headless-режим браузера.
- `--driver-path` — путь к бинарному файлу ChromeDriver, если требуется.
- `--min-delay` и `--max-delay` — минимальная и максимальная задержки между запросами.
- `--verbose` — включить вывод логов в консоль.

## Результат

- Excel-файл с колонками `company_url` и `email`. Несколько email-адресов сохраняются через запятую в одной ячейке.
- JSON-файл прогресса с последней обработанной страницей и ссылкой.
- Лог-файл с подробной информацией о выполнении и ошибках.

## Замечания

- Сайт динамический (SPA), поэтому элементы подгружаются асинхронно. Ожидания в коде
  настроены через `WebDriverWait`.
- При большом количестве запросов сайт может ограничивать частоту. При необходимости
  увеличьте задержки или используйте прокси.
- Соблюдайте условия использования сайта и требования законодательства о персональных данных.
